# Folio

> A social reading tracker — Letterboxd for books.

## Overview

Folio is a full-stack web application where readers can track every book they read, follow other readers, and discover new books through personalized recommendations. Built as a capstone project and portfolio piece demonstrating full-stack Laravel and Vue.js development.

## Features

- Google Books API integration for book search and rich metadata
- Personal library with reading status, star ratings, notes, and reviews
- Social follow system with personalized activity feed
- Book recommendations based on reading overlap with followed users
- Likes and comments on book log entries
- Public user profiles with follower/following counts
- WCAG 2.2 AA accessible throughout
- Toast notifications and loading states

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Laravel 13, PHP 8.4 |
| Frontend | Vue 3, Inertia.js, Tailwind CSS |
| Database | MySQL |
| Auth | Laravel Breeze |
| External API | Google Books API |
| Hosting | AWS EC2 |
